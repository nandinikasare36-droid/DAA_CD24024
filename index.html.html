How Merge Sort Works

Merge Sort repeatedly divides an array into smaller subarrays until every subarray contains one element. Then the subarrays are merged while comparing their elements to produce a sorted array.

What is Merge Sort?

Merge Sort is a comparison-based sorting algorithm based on the Divide and Conquer technique. It divides the input array into smaller parts, recursively sorts those parts and then merges them to obtain the final sorted array.

Key Characteristics

  • Uses Divide and Conquer strategy.
  • Divides the array into two halves.
  • Recursively sorts both halves.
  • Merges sorted halves.
  • Stable sorting algorithm.
  • Time complexity is O(n log n).
  • Requires additional memory.

Time & Space Complexity

Best Case

When the input is already favorable.

O(n log n)

Average Case

For a normal unordered array.

O(n log n)

Worst Case

Even when elements are arranged unfavorably.

O(n log n)

Space

Additional temporary arrays are required.

O(n)

Why O(n log n)?

The array is divided approximately log₂(n) times. At each level, the merging operation processes approximately n elements.


Therefore: n × log₂(n) = O(n log n)

Merge Sort Algorithm

1
Start

Take the input array.

2
Divide

Find the middle and divide the array into two halves.

3
Repeat

Continue dividing until each part has one element.

4
Compare

Compare the front elements of two sorted parts.

5
Merge

Place the smaller element into the new sorted array.

6
Complete

Continue until all elements have been merged.
